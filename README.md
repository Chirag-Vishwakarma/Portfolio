# Portfolio Website

Built a fully responsive portfolio website using HTML, SASS, Bootstrap & JavaScript.

## Live Demo

Vercel Link - https://portfolio-nine-orcin-ci6z68og3o.vercel.app/

## Source Code

Git Repo URL - https://github.com/Chirag-Vishwakarma

## Features

- Clean responsive layouts for mobile, tablet & desktop.
- Heavy CSS implementation
- Double Gradient Theme
- Heavily Interactive (like On Scroll Active section updates in Navbar, On Hover- Change in Theme, Opacity, Transform, Animation etc.)
- Animations (like Wave, Typing, Jumping, Dim-light, Gradient change etc.)
